# Agent-CI-Lens Protocol
## 🛑 HALT PROTOCOL (ABSOLUTE PRIORITY)
Okamžite zastav prácu a vytvor `.claude/cache/HALT.flag`, ak:
1. Vidíš `[attempts: 3]` v TASKS.md.
2. `security-guard` nájde tajomstvo.
3. Mypy hlási logickú chybu, ktorú nevieš opraviť.
4. Chýba API kredit.
## 🚀 STARTUP
1. `make validate` (Check environment)
2. `make status` (Check locks)
3. Čítaj `agent_context/TASKS.md`
## 🧠 WORKFLOW SYNTAX
- Tool Call: `<<<SKILL:name|args>>>`
- Context Update: `<<<SESSION:update_context|...>>>`
- Workspace Add: `<<<SESSION:add_workspace|src/file.py>>>`
